# Phone Agent для ПК (приложение с окном)

ИИ-агент управляет **телефоном по USB** или **самим компьютером**. Модели — из любого OpenAI-совместимого API,
в том числе бесплатных (выбор в окне: «Провайдер ИИ»).

## Скачать приложение (.exe)
Python устанавливать **не нужно**.

**Вариант 1 — готовый файл (рекомендуется).** Загрузите эту папку в свой репозиторий на GitHub. Сборка запустится
сама (или вручную: вкладка Actions -> «Build PhoneAgent.exe» -> Run workflow). Через 2–3 минуты в разделе
**Releases** (справа на главной странице репозитория) появится `PhoneAgent-Windows.zip`. Скачайте, распакуйте,
запустите `PhoneAgent.exe`. В архиве уже есть `adb` для режима телефона. Ссылку на релиз можно отправлять другим людям.

**Вариант 2 — собрать на своём ПК.** Двойной клик по `build.bat`: он сам скачает маленький Python в папку `.python`
(без прав администратора, систему не трогает), соберёт `dist\PhoneAgent.exe` и скачает `adb`. Папка `dist` — готовое
приложение, копируйте куда угодно.

## Бесплатные провайдеры
Выберите провайдера, нажмите «Получить ключ», вставьте ключ, нажмите «Список моделей». Ключ запоминается отдельно
для каждого провайдера. Лимиты бесплатных тарифов меняются — проверяйте на сайте провайдера (данные ниже на ноябрь 2026).

| Провайдер | Что нужно | Заметки |
|---|---|---|
| OpenCode Zen | ключ на opencode.ai/zen | бесплатные модели помечены `free` и `big-pickle` |
| OpenRouter | ключ на openrouter.ai/keys, карта не нужна | модели `:free`; лимит маленький (~20 запросов/мин, ~50/день без пополнения); `openrouter/free` выбирает случайную модель |
| Groq | ключ на console.groq.com/keys | быстро; ~30 запросов/мин, у больших моделей ~1000/сутки |
| Google Gemini | ключ на aistudio.google.com/apikey | есть вызов функций и картинки — подходит для режима ПК |
| Cerebras | ключ на cloud.cerebras.ai | очень быстро, ~30 запросов/мин |
| Mistral | ключ на console.mistral.ai, нужен телефон | тариф Experiment: запросы могут идти на обучение моделей |
| NVIDIA NIM | ключ на build.nvidia.com, нужен телефон | ~40 запросов/мин |
| Ollama (локально) | кнопка «Настроить Ollama» в окне | сама проверит ПК, установит Ollama и скачает модель; без ключа и лимитов |
| Ollama (облако) | ключ на ollama.com/settings/keys | модели на серверах Ollama, быстро на любом ПК; нужны кредиты или платный план |
| Свой сервер | любой OpenAI-совместимый адрес | LM Studio, vLLM и т.п. |

GitHub Models в список не включён: GitHub сообщает, что сервис закрыт с 30 июля 2026.

Агент делает один запрос к модели на каждый шаг, поэтому на тарифах с лимитом в десятки запросов в сутки
хватит на 1–2 небольшие задачи. Нужна модель с вызовом инструментов (tool calling); если модель отвечает текстом
и не действует, выберите другую.

## Ollama: установка и модели из приложения
Провайдер «Ollama (локально)» -> кнопка **«Настроить Ollama»**: показывает память и видеокарту, советует локальные или
облачные (`:cloud`, например `gemma4:cloud`) модели, ставит Ollama официальным установщиком (по вашему подтверждению),
скачивает выбранную модель (`ollama pull`). Для `:cloud` нажмите «Войти в аккаунт Ollama» и подтвердите вход в браузере:
приложение входит и создаёт ключи только по вашему действию.

## Как пользоваться
1. Выберите провайдера, вставьте ключ, выберите модель.
2. Выберите, что управляем, опишите задачу, нажмите «Запустить».
3. Ход работы виден в логе. Остановить можно кнопкой «Стоп» (в окне или на плавающей панели).

### Телефон по USB
- На телефоне: Настройки -> Для разработчиков -> «Отладка по USB», подключите кабель, подтвердите ключ.
- Скачайте [Android platform-tools](https://developer.android.com/tools/releases/platform-tools) и положите
  папку `platform-tools` рядом с `PhoneAgent.exe` (или добавьте `adb` в PATH).
- Текст не на латинице вводится только при установленной клавиатуре
  [ADBKeyBoard](https://github.com/senzhk/ADBKeyBoard).

### Этот компьютер
- Нужна модель **со зрением** (агент смотрит скриншоты): например Gemini или локальная модель со зрением в Ollama.
- Окно сворачивается, остаётся маленькая панель поверх всех окон: на ней текущее действие и кнопка «Стоп».
  По умолчанию включено подтверждение каждого действия («Выполнить» / «Пропустить»).
- Аварийная остановка: резко уведите мышь в угол экрана.
- macOS: права «Запись экрана» и «Универсальный доступ». Linux/Wayland не поддерживается.

## Безопасность
- Агент видит всё на экране; скриншоты и содержимое уходят выбранному провайдеру (у Ollama — остаются на ПК).
- Запреты на покупки, переводы, удаления и отправку сообщений заданы в промпте, но это не гарантия.
  Не отключайте подтверждение на компьютере с открытыми банками, почтой и мессенджерами.
- «Запомнить» сохраняет ключи в `~/.phone_agent.json` без шифрования (снимите галочку, чтобы не хранить).

## Терминальная версия
`python agent.py "задача" --provider groq --mode adb|desktop`, `--list-models`, `--model`, `--key`, `--yes`,
`--confirm`. Ключ можно задать переменной окружения: OPENCODE_API_KEY, OPENROUTER_API_KEY, GROQ_API_KEY,
GEMINI_API_KEY, CEREBRAS_API_KEY, MISTRAL_API_KEY, NVIDIA_API_KEY.
